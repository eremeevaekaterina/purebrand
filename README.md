# Pure Bistro — обучение

Единое приложение для обучения персонала Pure Bistro. Объединяет:

- [`menu/`](menu/) — меню и аллергены (из `dendrariy/pure-bistro-menu`)
- [`drinks/`](drinks/) — напитки (из `dendrariy/pure-bistro-drinks`)
- [`alco/`](alco/) — алкогольная карта (из `dendrariy/pure-bistro-alco`)

Главная страница `index.html` — навигация по разделам с прогрессом из localStorage.
Статический сайт, сборка не нужна; публикуется через GitHub Pages из ветки `main`.
